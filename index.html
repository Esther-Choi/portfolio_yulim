About me

React와 Node.js를 함께 다루는 풀스택 TypeScript 개발자입니다. 스펙의 빈틈과 예외 상황을 먼저 찾아내고, 복잡하고 변화하는 요구사항 속에서도 기능을 안정적으로 완성합니다.

프런트엔드와 백엔드를 모두 경험하며 UI 구현과 ERD 설계부터 API 연동, 결제 시스템, CI/CD 구축, 서비스 출시까지 전체 개발 사이클을 다뤄 왔습니다. 미국 회사 CRAA에서 미국 고객사 대상 서비스를 개발했고, CRAA와 Clap 모두 100% 원격 환경에서 일했습니다.
최근 2년간은 성과관리 SaaS Clap에서 권한과 상태에 따라 복잡하게 달라지는 평가 워크플로우를 설계하고 구현했습니다. 또한 Claude Code를 활용한 개발과 AI 기반 브라우저 자동화 QA를 실무에 적용해 개발 생산성과 기능 검증 과정을 개선해 왔습니다.

( 03 ) Engineering notes

Beyond the features

  1. 01

    Query Key Architecture

    흩어져 있던 React Query 쿼리 키 20여 개를 계층형 구조로 통합해 캐시 무효화 범위를 명확하게 관리할 수 있도록 개선했습니다.

    2025.09
  2. 02

    Request Hygiene

    중복 PUT 요청, 불필요한 통계 요청, 반복 발생하는 404, 불필요한 DELETE 요청을 찾아 원인을 개선하고 요청 흐름을 정리했습니다.

    Ongoing
  3. 03

    UI Consistency

    기존 공통 컴포넌트를 활용하고, 기존 테이블 화면을 공통 템플릿 기반으로 전환해 UI 일관성을 높였습니다.

    Component Reuse
  4. 04

    AI-assisted Development

    Claude Code를 활용한 개발 작업과 브라우저 자동화 QA를 실무에 적용했습니다. 반복적인 피처 플래그 제거 작업을 위한 Claude Code 스킬도 개선했습니다.

( 05 ) Working with me

What teammates say

아래에서 동료들의 피드백에 반복적으로 등장한 일하는 방식과 강점을 소개합니다.

  1. 01

    빈틈을 먼저 찾습니다

    기획에서 놓친 부분, 명세 누락, API 스펙 오류, 테스트 범위 밖의 영향 지점까지 먼저 찾아 공유했습니다.

  2. 02

    변화 속에서도 끝까지 마무리합니다

    잦은 스펙 변경 속에서도 복잡한 기능을 빠르게 완성했고, 릴리즈 후 QA 및 Live 이슈에도 신속하게 대응했습니다.

  3. 03

    논리적으로 설명하고 기록합니다

    질문과 답변, 문제 API와 계정을 문서로 정리했습니다. 문제 상황과 기술적 맥락을 명확하게 설명해 의사결정을 돕고, 요구사항과 기술 문서 간의 연결을 명확히 했습니다.

  4. 04

    구현을 넘어 설계에 참여합니다

    권한을 잃었을 때의 동작을 설계하며 데이터 조회와 액션의 경계를 구분하자고 제안해 UX 방향을 정했습니다. 다른 피처와 겹치는 부분도 미리 파악해 대응 방향을 조율했습니다.

  5. 05

    팀 전체의 품질을 살핍니다

    기존 컨벤션과 공통 컴포넌트를 활용해 코드 일관성을 유지하고, 다른 피처의 동일한 결함이나 다국어 빌드 오류도 발견 즉시 공유하고 대응했습니다. 동료의 업무 적응도 도왔습니다.
