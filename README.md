# portfolio-yulim

Personal portfolio — Vite + TypeScript, GSAP (ScrollTrigger), Lenis.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Deploy: import the repo on Vercel (framework preset: Vite) — no extra config needed.

- Content: `index.html` (about / experience / contact), `src/data.ts` (projects)
- Images: `public/img/`
